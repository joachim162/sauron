# Tech Stack
#tech #perl #mojolicious #openapi

The project uses a Perl-centric stack to ensure seamless integration with the existing Sauron modules.

## Components
- **Mojolicious:** A real-time web framework for Perl.
- **Mojolicious::Plugin::OpenAPI:** Provides validation and routing based on an OpenAPI spec.
- **PostgreSQL:** The underlying database (accessed via `DBI` and `DBD::Pg`).
- **Sauron Modules:** Custom Perl modules located in `~/sauron/Sauron/`.
